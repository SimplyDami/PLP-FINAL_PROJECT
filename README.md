## 🏥 Overview

**Ilorin eHospital** is a comprehensive healthcare management platform designed to revolutionize how patients and healthcare providers interact. This system provides seamless appointment booking, medical record management, and healthcare service access through an intuitive, user-friendly interface.

### Key Benefits
- **For Patients**: Easy appointment scheduling, health record access, and medication tracking
- **For Providers**: Efficient patient management, schedule optimization, and digital record-keeping
- **For Clinics**: Streamlined operations, reduced paperwork, and improved patient satisfaction

## ✨ Features

### 🔐 User Authentication & Security
- Secure user registration and login
- Role-based access control (Patient, Doctor, Admin)
- Password encryption and session management
- Protected routes and API endpoints

### 📅 Appointment Management
- **Book Appointments**: Find available slots and book with preferred doctors
- **Appointment History**: View past and upcoming appointments
- **Reschedule/Cancel**: Flexible appointment modifications
- **Reminder System**: Email/SMS notifications for upcoming appointments

### 👨‍⚕️ Doctor & Patient Profiles
- **Doctor Profiles**: Specialization, experience, availability, ratings
- **Patient Profiles**: Medical history, contact information, preferences
- **Profile Management**: Easy updating of personal and medical information

### 💊 Health Records
- Digital health record storage
- Prescription management
- Lab results tracking
- Medical history maintenance
- Secure data encryption

### 🏥 Clinic Management
- Multiple clinic support
- Doctor scheduling
- Room and resource management
- Operational analytics

## 🛠 Technology Stack

### Frontend
- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with Flexbox/Grid
- **JavaScript (ES6+)** - Client-side functionality
- **Responsive Design** - Mobile-first approach

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web application framework
- **Database** - MySQL/MongoDB

### Additional Technologies
- **RESTful API** - Standardized communication
- **JWT** - Secure authentication
- **bcrypt** - Password hashing

## 🚀 Installation

### Prerequisites
- To run:
-  Copy .env.example to .env and set MONGODB_URI
-  npm install
-  npm run seed
-  npm run dev
