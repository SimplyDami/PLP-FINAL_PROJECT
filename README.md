# Ilorin eHospital Backend

This backend provides a simple Express + MongoDB API for the Ilorin eHospital final year project.

Features:
- JWT authentication
- User, Patient, Doctor, Appointment models
- Seed script to populate sample data

To run:
1. Copy .env.example to .env and set MONGODB_URI
2. npm install
3. npm run seed
4. npm run dev
